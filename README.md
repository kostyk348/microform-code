# Microform Code

Высокоплотный 2D-код на основе микро-форм (эллипсы, капли, текстуры).

**Идея:** вместо чёрно-белых модулей QR используем непрерывный орнамент из микро-элементов, где каждый элемент несёт 10-20 бит через модуляцию формы, угла, размера и внутренней текстуры.

**Цель:** ×10-100 к ёмкости QR при том же физическом размере и обратной совместимости по каналу (бумага + камера телефона).

## Структура проекта

```
generator.py     — генератор паттерна для печати
decoder.py       — декодер: фото → параметры → данные
ecc.py           — помехоустойчивое кодирование (Reed-Solomon / LDPC)
tests/           — тестовые печати, фото, замеры
```

## Фазы

1. **Генератор** — сетка эллипсов с модуляцией угла/размера/удлинения (текущая)
2. **Калибровка** — маркеры для коррекции перспективы и контраста
3. **Декодер** — выделение и измерение микро-форм по фото
4. **ECC** — Reed-Solomon поверх данных
5. **Multi-element** — 2-3 подэлемента на ячейку (×2 ёмкости)
6. **Текстура** — штриховка внутри формы (ещё +5 бит/ячейку)

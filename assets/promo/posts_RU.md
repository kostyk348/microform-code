# Анонс-посты для Microform Code (RU)

## Hacker News (Show HN, EN)

**Show HN: Microform Code — бумажный 2D-код с 17 битами на ячейку (×5 к QR)**

Питоновский прототип доведён до полноценного Rust-крейта. Каждая ячейка
несёт 17 бит — эллипс (угол/масштаб/вытянутость, 10 бит) плюс
микро-точка со сдвигом (7 бит), битовый поток защищён RS(255,223).
Стикер 30×30 мм при 300 мкм/ячейку хранит 15.2 КБ — против ~3 КБ у
QR-40 того же размера.

Главная идея — декодирование как *точный lookup пиксельного тайла* по
детерминированному кодбуку: из 262 144 комбинаций параметров 184 154
дают визуально различные тайлы, кодек использует ровно 2¹⁷ из них. Без
эвристик: ячейка либо известный тайл, либо *известно отсутствующий* —
и отсутствующие становятся стёртиями Рида–Соломона (восстанавливается
10 ячеек на блок против 5 ошибок с неизвестными позициями). Один
RS-блок — ровно 120 ячеек, повреждения не расползаются между блоками.

Честная граница заявлена прямо: чистый растр декодируется на любом
масштабе печати (шаг сетки измеряется по маркерам, таблица кодов
подстраивается), но шум, размытие и фотография ломают точный хеш —
декодирование с камеры требует перцептивного сопоставления, это
дорожная карта, а не заявление. `microform demo` — 8 детерминированных
проверок за ~2 с.

Зависимости две (`png`, `reed-solomon`); Отсу, эрозия, связные
компоненты и решатель гомографии написаны в самом крейте. 24 теста,
Apache-2.0.

https://github.com/kostyk348/microform-code

## Reddit r/rust (текст поста, EN)

**microform 1.0.0 — 2D-код для бумаги, 17 бит/ячейку, Rust-крейт с двумя зависимостями**

Заменил питоновский прототип (cv2 + numpy + reedsolo, декод на одном
жёстком масштабе) на реализацию с нуля. Всё, кроме PNG-ввода-вывода и
Рида–Соломона, написано руками: порог Отсу, эрозия, поиск маркеров по
связным компонентам, точная 4-точечная гомография, масштабо-осведомлённый
кодбук и CLI без clap.

Инженерные детали:
- детерминированная сборка кодбука (~0.4 с, без кэш-файла) — одинаковые
  байты на любой машине, проверено тестами;
- масштабо-осведомлённое декодирование: шаг сетки выбирает кодбук из
  тайлов, уникальных на *этом* масштабе; битовая глубина ячейки
  подстраивается (17→15→12 бит, всегда делитель 2040-битного блока);
- RS-стёртия для «известно отсутствующих» ячеек: штамп поверх 10 ячеек
  блока всё ещё декодируется;
- частичные RS-блоки — маленькие сетки теперь полезны.

Цифры: 92×92 ячейки при 300 мкм → 15.2 КБ в 30×30 мм (×5 к QR-40);
150×150 при 200 мкм → 35.9 КБ. Ограничение названо прямо: точный lookup
переживает чистые растры, но не камеру — это дорожная карта.

https://github.com/kostyk348/microform-code

## Telegram-канал (короткий пост)

🖨️ **Microform Code 1.0.0** — бумажный код плотностью 17 бит/ячейку.
Эллипс + микро-точка в каждой ячейке, детерминированный кодбук на
2¹⁷ уникальных тайлов, RS(255,223) со стёртиями: штамп поверх десятой
части блока не мешает декодированию. Стикер 30×30 мм = 15 КБ (×5 к
QR-40), при 200 мкм — уже 36 КБ.

Python-прототип переписан на Rust с нуля: две зависимости (`png`,
`reed-solomon`), остальное — Отсу, эрозия, гомография, CLI — своё.
24 теста, демо на 8 честных проверок за 2 секунды. Отдельно нравится
позиция проекта: точный lookup переживает принтер, но не камеру — и
об этом сказано прямо, в README и в LIMITATIONS.

https://github.com/kostyk348/microform-code

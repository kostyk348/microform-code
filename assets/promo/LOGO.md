# Логотип Microform Code — текстовая концепция

## Идея

**Микрокадр: лист бумаги под микроскопом.** Знак — квадратный «кадр»
с рамкой-перфорацией (как у плёнки microform, давшей имя проекту);
внутри кадра — плотное поле из трёх эллипсов разного наклона и одной
микро-точки, читающееся как увеличенный фрагмент настоящего кода.
Метафора: данные, отпечатанные на бумаге и рассматриваемые под лупой.

## Геометрия

- Сетка построения — 24×24, знак вписан в квадрат со скруглением 2;
- внешняя рамка — линия толщиной 2 единицы с «перфорацией»: по 4
  коротких штриха на сторону (отсылка к кадру микрофильма);
- внутри — поле 12×12 из упрощённых ячеек; три ячейки крупные
  (эллипсы 45°, 90°, 135° с точкой-спутником у каждой), остальные —
  мелкие точки случайной (зафиксированной seed'ом) плотности;
- микро-точка-акцент радиусом 1.5 смещена к правому верхнему эллипсу —
  «сигнал» среди текстуры;
- минимальный размер узнаваемости — 24 px (favicon): рамка и три
  эллипса сохраняются, текстура упрощается до сетки 4×4.

## Палитра

| роль | цвет | где |
| --- | --- | --- |
| фон | `#0D1117` (GitHub-dark) | тёмные поверхности |
| бумага | `#F6F8FA` | светлые поверхности, подложка кадра |
| знак | `#1F2328` (тушь) | рамка, эллипсы, точки на светлом |
| акцент | `#0969DA` (чернила) | микро-точка-сигнал, favicon |
| перфорация | `#8C959F` | штрихи рамки, вторичный текст |

## Словесное сопровождение

- рядом со знаком — «Microform Code» набором `ui-monospace`;
- тэглайн: «Paper is the storage medium» / «Бумага — носитель»;
- вfavicon-размерах допустимо использовать только кадр с одним
  эллипсом и точкой.

## Где применимо

- README-шапка и OG-картинка: знак на фоне реального кода 92×92;
- иконка CLI-проекта (терминал): кадр 24 px без текста;
- печать: знак сам может быть «напечатан» средствами генератора —
  эллипсы и точка повторяют ячейки кода (подпись «the logo is a
  Microform Code» — честная шутка для промо).
